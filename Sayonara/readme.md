撒油拿拉 Sayonara V0.9.1
让所有欺负过PC的人都付出代价。
以下涉及对模组内容的剧透，谨慎观看
<details>
<summary>修改事件一：River揪pc耳朵</summary>

数学课上有时river会把pc转化的耳朵当成发圈企图揪下来。增加一个利用转化本身特质吓退river的选项。
</details>
<details>
<summary>修改事件二：River的提问</summary>

原版中此事件为两难抉择，增加第三个选项，数学成绩够高的pc可以尝试反过来难住River，此时不掉声望或增加违规。
</details>
<details>
<summary>修改事件三：放学留堂</summary>

新增选项，可以在留堂时利用各种动物转化特质在礼顿的办公室捣乱，如果此间礼顿离开办公室，捣乱将进一步升级
</details>
<details>
<summary>修改事件四：礼顿的检查</summary>

科学课上礼顿来"检查"时，诡术足够高的玩家可以偷偷从后门溜走，在外面进行捣乱，阻挠礼顿的检查。
</details>
<details>
<summary>修改事件五：图书馆失窃惩罚</summary>

除了给礼顿一拳，现在pc还可以凭借诡术扒掉礼顿的裤子。一共有12种不同稀有度和图案的内裤等待发现。
内裤图鉴位于“日志”界面最下方。
</details>
