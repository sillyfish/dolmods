SwipeNav 滑动翻页 V0.1.1
### 功能
* 页面顶部加了"上一步/下一步"两个按钮。
* 全屏左右滑动翻页：从左往右滑 = 回到上一步，从右往左滑 = 前进到下一步。
* 横向滑动会优先给本mod，原版的右滑拉出侧栏被拦下了，侧栏用左上角箭头打开。
* 按钮固定在主界面中部，不跟着侧栏移动。
### 设置
打开 swipenav.js，最上面的 CONFIG 可以改：
* position：快捷回溯按键位置：'left' 箭头旁边 / 'center' 顶部中间
* minDistance：滑多远才算翻页
* directionRatio：横向要比纵向大几倍，越大越不容易误触
### 注意
* 按钮是灰的、滑了没反应：游戏设置里的历史记录/回溯步数可能是 0 或 1，调大才有东西可退。
